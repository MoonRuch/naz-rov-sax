# Назаров Максим — сайт-визитка

Статический сайт для GitHub Pages.

## Что заменить
- Фото: заменить блок `.photo-placeholder` в `index.html` на `<img>` и добавить фотографию в `assets/`.
- Ссылки VK / Telegram.
- E-mail.
- Тексты об опыте.
- Видео/аудио карточки.

## Публикация
Загрузить `index.html`, `style.css`, `script.js` и папку `assets` в репозиторий GitHub и включить GitHub Pages.
